## Sobre

Este é o repositório do Trabalho de Conclusão de Curso sobre compiladores e
algoritmos de aprendizado de máquina. Para mais informações,
[leia o artigo](./thesis/TCC.pdf).

## Dependências

- Ubuntu 26.04.1 LTS (kernel 6.18.33.2) no WSL 2
- GNU Make 4.4.1-3
- liblapacke e liblapacke-dev 3.12.1-7
- libopenblas 0.3.32+ds-5
- GNU Compiler Collection (GCC 15)
- LLVM (Clang 21)

## Execução

1. Certifique-se que as dependências estão instaladas.
2. Abra um terminal e navegue para o diretório raíz do projeto.
3. Digite o seguinte comando, e depois aperte Enter no teclado. Isso compilará
e executará o projeto.

```bash
./PROGRUN.sh
```

4. Para limpar os arquivos gerados, digite:

```bash
make clean
```
