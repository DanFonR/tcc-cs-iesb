## Dependências

- Distribuição Linux
- GNU Make
- GNU Compiler Collection (GCC)
- LLVM (Clang)
- OpenMP

## Execução

1. Certifique-se que as dependências estão instaladas.
2. Abra um terminal e navegue para o diretório raíz do projeto.
3. Digite o seguinte comando, e depois aperte Enter no teclado. Isso compilará
o projeto.

```bash
make -j
```

4. Para executar, digite o seguinte comando, e depois aperte Enter.

```bash
./bin/main
```

5. Para limpar os arquivos gerados, digite:

```bash
make clean
```
